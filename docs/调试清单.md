## W1 — RAG + 意图路由 + 基础 API

| # | 测试项 | 类型 | 命令 / 操作 | 预期结果 | 备注 |
|---|--------|------|-------------|----------|------|
| 1 | KB 文档入库 | AUTO | `make test -k test_rag` | BM25 + 向量检索命中率 > 0 | 需先 `python -m scripts.ingest_kb` |
| 2 | 意图路由分类 | AUTO | `make eval-smoke` | greeting / knowledge / business 三类准确率 | eval dataset 中覆盖 3 类 |
| 3 | RAG 引用卡片 | MANUAL | 浏览器发 "退货政策是什么" | 返回含 `[[KB-xxx]]` 引用标记 | `RAG_USE_LOCAL_FALLBACK=true` 时用本地兜底 |
| 4 | SSE 流式输出 | MANUAL | `curl -N POST /api/v1/chat` | 看到 `event:` + `data:` 逐行输出 | 加 `Accept: text/event-stream` |

**调试备注：**
- RAG 本地兜底模式（`RAG_USE_LOCAL_FALLBACK=true`）不走 Qdrant，用关键词匹配，精度低但可离线跑

- SSE 响应必须加 `stream=True` + `Accept: text/event-stream`，否则 FastAPI 返回 JSON
